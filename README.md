# SQLマスターへの道 Ver3 完成版

GitHub Pagesで動作する静的Webサイトです。外部ライブラリやビルド作業は不要です。

## Ver3の内容

- UNIT 0「データベース入門」を追加
- データベース、テーブル、行・列、SQLをHTML/CSS図解で説明
- SQL単語組み立てゲーム
- UNIT 1～10の図解付き解説
- 解説、選択問題、穴埋め、意味確認、自力記述の5段階
- 11ユニット、合計55ステップ
- XP、ハート、進捗、バッジ
- localStorageによるブラウザ内保存
- スマートフォン対応

## GitHub Pagesへの反映

1. ZIPを展開します。
2. 既存のGitHubリポジトリを開きます。
3. 既存ファイルを削除するか、同名ファイルを上書きします。
4. 次の5ファイルをリポジトリ直下へアップロードします。
   - index.html
   - style.css
   - app.js
   - lessons.js
   - README.md
5. Commit changesを押します。
6. GitHub Pagesが main / (root) なら自動的に更新されます。
7. 公開ページで Ctrl + F5 を押して再読み込みします。

## 旧版からの注意
